# 02-message-content

이 문서는 Agent core의 **Message/Role/Content 타입**, **multimodal content**, **response/update/usage/finish reason**, **normalization**, **message-content-stream model**만 다룬다. 범위 내에서 .NET core는 자체 Message/Content 타입을 새로 정의하지 않고 `Microsoft.Extensions.AI`의 `ChatMessage`, `ChatRole`, `AIContent`, `ChatResponse`, `ChatResponseUpdate`를 감싼 `AgentResponse`/`AgentResponseUpdate` 중심으로 동작한다. 반대로 Python core는 `Content`, `Message`, `ChatResponse`, `ChatResponseUpdate`, `AgentResponse`, `AgentResponseUpdate`, `ResponseStream`를 직접 정의한다. ## Java 결정

- Java는 Python처럼 **core-owned Message/Content/Response model**을 두는 편이 좋다. .NET처럼 외부 AI SDK 타입을 그대로 public core surface에 노출하면 multimodal taxonomy, approval content, hosted asset, MCP informational-only 규칙 같은 core semantics의 진화를 외부 라이브러리에 종속시키게 된다. [AIContentExtensions.cs#L16-L61](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/AIContentExtensions.cs#L16-L61) [_types.py#L484-L590](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L484-L590)
- 구체적으로는 Java에서 `Message`는 `role + List<Content>` 구조를, `Content`는 sealed hierarchy 또는 tagged union 스타일을 택하는 것이 좋다. Python처럼 하나의 tagged class에 모두 담는 방식은 직렬화가 단순하지만, Java에선 sealed interface + subtype record가 더 안전할 수 있다. 다만 `additionalProperties`와 `rawRepresentation` escape hatch는 반드시 유지해야 provider-specific metadata를 잃지 않는다. [_types.py#L538-L551](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L538-L551) [AgentResponse.cs#L219-L240](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/AgentResponse.cs#L219-L240)
- stream model은 Python의 `ResponseStream` 같은 generic wrapper를 유지하되, .NET처럼 update↔response conversion helper를 별도 utility로 제공하는 이중 구조가 적절하다. 그래야 streaming과 non-streaming consumer가 같은 message/content model을 공유하면서도 finalizer/hook/gate semantics를 명확히 드러낼 수 있다. [AgentResponseExtensions.cs#L106-L176](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/AgentResponseExtensions.cs#L106-L176) [_types.py#L3061-L3515](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L3061-L3515)
