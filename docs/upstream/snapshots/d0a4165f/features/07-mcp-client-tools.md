# 07-mcp-client-tools

이 문서는 Agent Framework의 **MCP client tools**만 다룬다. 범위는 Python core의 `MCPStdioTool` / `MCPStreamableHTTPTool` / `MCPWebsocketTool`, 이들의 **client lifecycle**, **tool discovery / invocation**, **prompts / resources 경계**, **sampling approval callback**, **MCP long-running task(SEP-2663) 처리**, **trace / error / cancellation / security**이며, reviewed .NET 쪽은 transport-specific tool surface가 아니라 **existing `McpClient`를 agent tool로 노출하는 long-running task wrapper**에 초점이 있다. **MCP hosting/server 구현**은 별도 문서 범위다. ## 목적

이 기능의 목적은 외부 MCP server를 **agent가 호출할 수 있는 tool/prompt surface**로 연결하고, transport 차이(stdio / HTTP / WebSocket), discovery, sampling, long-running task lifecycle, security guardrail을 감싸는 것이다. Python은 `MCPTool` base가 connection management, discovery, tool invocation, prompt invocation, sampling callback, long-running task를 통합하고, transport subclasses가 각 transport client 생성만 specialize한다. .NET reviewed package는 `McpClient.ListToolsAsync()` 결과를 `AIFunction`으로 노출하고, task-capable tool에만 `TaskAwareMcpClientAIFunction`을 감싸는 방식으로 long-running task를 agent tool loop에 숨긴다. [_mcp.py#L396-L412](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L396-L412) [_mcp.py#L414-L559](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L414-L559) [McpClientTaskExtensions.cs#L19-L33](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Mcp/McpClientTaskExtensions.cs#L19-L33) [TaskAwareMcpClientAIFunction.cs#L22-L39](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Mcp/TaskAwareMcpClientAIFunction.cs#L22-L39)

- MCP client tool transport surface

- sampling callback approval과 request limiting
- long-running task lifecycle
- tracing, errors, cancellation, header / metadata security [ _mcp.py#L1271-L1395](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1271-L1395) [_mcp.py#L1692-L1933](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1692-L1933) [_mcp.py#L2033-L2661](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L2033-L2661) [McpTaskOptions.cs#L7-L39](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Mcp/McpTaskOptions.cs#L7-L39)

## Client lifecycle

### Python

- `MCPTool.connect(reset=False)`는 lifecycle owner task / queue 모델을 통해 connect를 직렬화한다. 외부 caller가 직접 connect해도 실제 connect/close는 owner task에서 수행된다. [_mcp.py#L1124-L1210](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1124-L1210) [_mcp.py#L1271-L1279](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1271-L1279)

[_mcp.py#L1280-L1405](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1280-L1405)

[_mcp.py#L1971-L2008](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1971-L2008)

## Tool discovery / invocation

### Python discovery

- `load_tools()`는 server `tools/list`를 paginated로 순회하고, 각 remote tool을 local `FunctionTool`로 변환한다. input schema는 zero-arg object tool을 위해 `properties`가 없으면 `{}`를 보충한다. [_mcp.py#L1785-L1933](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L1785-L1933)
- `tool_name_prefix`는 local name에 접두어를 붙이되, allowlist/approval matching은 raw remote name과 normalized/local name의 안전한 candidate 집합으로 수행한다. [_mcp.py#L188-L205](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L188-L205) [_mcp.py#L874-L885](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_mcp.py#L874-L885)
