# 05-function-tools

이 문서는 Agent core의 **function tool 정의/데코레이터/schema 생성**, **argument validation/parsing**, **tool mode/selection**, **invocation configuration/layer/budget**, **parallel call과 execution result semantics**만 다룬다. **Tool approval**과 **MCP**는 별도 문서 범위이므로, 여기서는 해당 기능과 만나는 경계만 기술한다. .NET pinned core는 Python처럼 first-class `FunctionTool`/`@tool` abstraction을 정의하지 않고, 외부 `AITool`/`AIFunction`을 받아 `FunctionInvokingChatClient` 및 function middleware wrapper로 연결한다. 반면 Python core는 `FunctionTool`, `@tool`, `FunctionInvocationConfiguration`, `FunctionInvocationLayer`를 직접 제공하며, schema inference와 invocation 결과 표준화까지 core가 소유한다. [FunctionInvocationDelegatingAgent.cs#L30-L68](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgent.cs#L30-L68) [ChatClientAgent.cs#L82-L92](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientAgent.cs#L82-L92) [_tools.py#L252-L419](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L252-L419) [_tools.py#L1326-L1403](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1326-L1403) [_tools.py#L2845-L2868](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L2845-L2868)

## 목적

이 기능의 목적은 모델이 호출할 수 있는 함수를 **도구 정의 + 입력 schema + 실행 규칙 + 결과 표준화**의 형태로 다루는 것이다. Python core는 함수 시그니처나 명시적 schema에서 JSON schema를 만들고, 호출 시 입력을 validate하며, 결과를 `list[Content]`로 정규화한다. .NET core는 이미 만들어진 `AITool`/`AIFunction`를 agent lifecycle에 연결하고, 필요하면 function middleware를 끼워 넣는 데 집중한다. [ _tools.py#L310-L419](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L310-L419) [_tools.py#L810-L897](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L810-L897) [FunctionInvocationDelegatingAgentBuilderExtensions.cs#L17-L51](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgentBuilderExtensions.cs#L17-L51)

## 경계

이 문서는 다음을 포함한다.

- Python `FunctionTool`과 `@tool` 데코레이터
- 명시적 schema vs 시그니처 추론
- `tool_choice` / `ToolMode` 기반 selection semantics
- `FunctionInvocationConfiguration`와 `FunctionInvocationLayer`
- parallel function execution, per-run budget, 결과 변환 규칙 [ _tools.py#L493-L523](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L493-L523) [_tools.py#L1079-L1126](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1079-L1126) [_tools.py#L1326-L1403](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1326-L1403) [_tools.py#L1710-L1850](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1710-L1850)

## 공개 API·타입

### Python

- `FunctionTool`의 핵심 필드는 `name`, `description`, `approval_mode`, `kind`, `max_invocations`, `max_invocation_exceptions`, `func`, `input_model`, `result_parser`다. `func=None`이면 declaration-only tool이 된다. [_tools.py#L310-L419](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L310-L419) [_tools.py#L453-L460](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L453-L460)
- `tool()` 데코레이터는 함수 직접 장식(`@tool`)과 파라미터화된 decorator(`@tool(...)`) 둘 다 지원하며, `schema`, `approval_mode`, `kind`, `max_invocations`, `max_invocation_exceptions`, `additional_properties`, `result_parser`를 받을 수 있다. [_tools.py#L1130-L1173](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1130-L1173)
- `FunctionInvocationConfiguration`은 `enabled`, `max_iterations`, `max_function_calls`, `max_consecutive_errors_per_request`, `terminate_on_unknown_calls`, `additional_tools`, `include_detailed_errors`를 가진다. [_tools.py#L1326-L1380](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1326-L1380)
- `FunctionInvocationLayer`는 chat client에 function-calling loop를 끼워 넣는 layer다. [_tools.py#L2845-L2868](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L2845-L2868)

[_types.py#L3640-L3651](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L3640-L3651) [_types.py#L3703-L3706](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L3703-L3706)

## Function tool definition / decorator / schema generation

### Python

- `FunctionTool`은 명시적 `input_model`이 없으면 `_resolve_input_model()`에서 함수 시그니처를 읽어 Pydantic `create_model()`로 입력 모델을 합성한다. 이때 `self`/`cls`, context parameter, `*args`/`**kwargs`는 schema에서 제외된다. [_tools.py#L493-L523](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L493-L523)
- context injection은 `_discover_injected_parameters()`와 `_is_context_parameter()`가 맡는다. 타입 힌트에 `FunctionInvocationContext`가 포함되면 해당 파라미터는 런타임에 주입되고, 명시적 input model이 있을 때는 annotation 없는 `ctx` 이름도 special-case로 인식한다. [_tools.py#L420-L445](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L420-L445)
- `parameters()`는 lazily generated JSON schema를 캐시해 반환한다. `_input_schema`는 explicit JSON schema dict면 그대로, explicit/inferred Pydantic model이면 `model_json_schema()` 결과를 쓴다. [_tools.py#L797-L819](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L797-L819)
- `tool()` 데코레이터 문서는 explicit `schema`가 Pydantic `BaseModel` 또는 JSON schema dict일 수 있고, dict schema는 `properties`가 있는 flat object schema여야 하며 `oneOf`, `$ref`, nested composition 같은 복잡한 JSON Schema 기능은 지원하지 않는다고 명시한다. [_tools.py#L1174-L1205](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1174-L1205)
- pinned tests는 시그니처 추론, explicit Pydantic schema, explicit JSON schema dict, custom schema extension field 보존을 검증한다. [test_tools.py#L33-L68](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L33-L68) [test_tools.py#L71-L89](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L71-L89) [test_tools.py#L92-L128](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L92-L128) [test_tools.py#L245-L269](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L245-L269) [test_tools.py#L288-L303](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L288-L303)

### .NET

- pinned core에는 Python `@tool`에 해당하는 first-class decorator나 schema inference helper가 없다. function tool definition은 외부에서 준비된 `AITool`/`AIFunction`를 agent에 넣는 방식이다. ## Argument validation / parsing

### Python

- `FunctionTool.invoke()`는 declaration-only tool을 즉시 거부하고, `arguments`, `context.arguments`, direct kwargs 중 어느 경로에서 입력을 받을지 정리한다. direct kwargs는 반드시 선언된 tool parameter와 일치해야 하며, runtime data는 `FunctionInvocationContext`로만 전달해야 한다. [_tools.py#L586-L649](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L586-L649)
- inferred or explicit Pydantic model 경로에서는 `model_validate(...).model_dump(exclude_unset=True)`를 사용한다. null을 explicit하게 준 값은 유지하고, 모델이 생략한 값만 제거해 함수의 Python default가 적용되게 한다. [_tools.py#L655-L690](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L655-L690)
- explicit JSON schema dict 경로에서는 `_validate_arguments_against_schema()`가 required field, `additionalProperties: false`, enum membership, scalar type/list-of-types를 lightweight하게 검사한다. [_tools.py#L1079-L1126](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1079-L1126)
- 함수 호출 payload를 모델이 JSON 문자열로 보낼 때는 `Content.parse_arguments()`가 먼저 object/non-object를 구분해 dict 또는 `{"raw": ...}`로 바꾼다. 이 parsing은 function tool invocation layer의 upstream 단계다. [_types.py#L1612-L1652](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L1612-L1652)
- pinned tests는 explicit schema tool invoke, `skip_parsing=True` 경로에서도 동일한 argument validation이 적용되는 점, unexpected runtime kwargs가 거부되는 점을 검증한다. [test_tools.py#L272-L285](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L272-L285) [test_tools.py#L1468-L1487](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_tools.py#L1468-L1487)

### .NET

- pinned core source에는 Python식 function argument schema generation/validation이 없다. function middleware wrapper는 이미 준비된 `AIFunctionArguments`를 ambient `FunctionInvocationContext` 또는 새 context에 담아 `AIFunction.InvokeCoreAsync()`로 넘긴다. [FunctionInvocationDelegatingAgent.cs#L70-L87](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgent.cs#L70-L87)

## Invocation configuration / layers / budgets

### Python

- `normalize_function_invocation_configuration()`는 default `enabled=True`, `max_iterations=DEFAULT_MAX_ITERATIONS`, `max_function_calls=None`, `max_consecutive_errors_per_request=DEFAULT_MAX_CONSECUTIVE_ERRORS_PER_REQUEST`, `terminate_on_unknown_calls=False`, `additional_tools=[]`, `include_detailed_errors=False`를 공급하고, 수치 제약을 검증한다.
