# 10. Middleware

## 1. 상태

이 commit의 middleware 표면은 두 갈래다. **.NET**은 `AIAgent`/`IChatClient`를 데코레이터로 감싸는 builder 중심 구조이고, **Python**은 `AgentMiddleware`/`ChatMiddleware`/`FunctionMiddleware`의 3-seam typed pipeline이 중심이다. message injection, tool approval, per-service-call persistence, agent-hooks 같은 인접 기능도 이 middleware seams를 통해 결합된다. ([AIAgentBuilder](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L13-L178), [ChatClient default stack](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientExtensions.cs#L52-L139), [Python middleware seams](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L477-L681), [Python session injection middleware](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_sessions.py#L1279-L1432), [agent-hooks bundle intro](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_agent_hooks.py#L3-L20))

## 2. 목적·경계

middleware의 목적은 agent run, chat model call, function/tool invocation의 **전·후에 입력·상태·결과를 관찰하거나 바꾸고, 필요하면 short-circuit**하는 것이다. .NET은 `DelegatingAIAgent`와 `AIAgentBuilder.Use(...)`로 이를 제공하고, Python은 context 객체와 `call_next()`를 받는 seam별 middleware protocol로 동일한 목적을 푼다. ([DelegatingAIAgent remarks](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/DelegatingAIAgent.cs#L13-L27), [AIAgentBuilder Use overloads](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L72-L178), [AgentMiddleware docs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L477-L533), [FunctionMiddleware docs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L536-L597), [ChatMiddleware docs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L600-L662))

이 문서는 다음을 포함한다.

- .NET agent/function/chat middleware builder·decorator 구조
- Python contexts/layers/bundles/decorators
- ordering/nesting, `next` invocation, mutation, termination, exception behavior
- async/streaming/cancellation
- hooks와 message injection/tool approval의 **접점**

이 문서는 다음을 재서술하지 않는다.

- tool approval request/response의 상세 payload 계약
- message injection의 사용자 경험/샘플 절차 전체

대신 middleware가 approval/message injection과 **어디서 연결되는지**만 기록한다. .NET은 `ChatClientAgentOptions`에서 approval/message injection/persistence toggles를 배선하고, Python은 function middleware가 approval request를 반환하거나 replay approval response를 `metadata["approval_response"]`로 관찰할 수 있으며, chat middleware가 session queue를 drain한다. ([ChatClientAgentOptions approval/message injection flags](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientAgentOptions.cs#L95-L276), [Python function approval touchpoint](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L1576-L1626), [Python message injection touchpoint](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_sessions.py#L1298-L1432))

## 3. 성숙도

### 3.1 .NET

- `AIAgentBuilder`, `UseLogging`, `UseOpenTelemetry`, function-middleware builder extension은 public API다. ([AIAgentBuilder](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L13-L178), [UseLogging](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/LoggingAgentBuilderExtensions.cs#L12-L65), [UseOpenTelemetry](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/OpenTelemetryAgentBuilderExtensions.cs#L8-L58), [function middleware extension](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgentBuilderExtensions.cs#L11-L52))
- 실제 function wrapper인 `FunctionInvocationDelegatingAgent`는 `internal` 구현체다. 즉 public contract는 **extension method + callback shape**이고, concrete wrapper는 내부 세부다. ([FunctionInvocationDelegatingAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgent.cs#L12-L88))
- middleware 인접 기능 중 `EnableInvocableFunctionBypassing`와 `OpenTelemetryAgent(..., autoWireChatClient)`는 `[Experimental]`이다. ([ChatClientAgentOptions experimental flag](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientAgentOptions.cs#L243-L276), [OpenTelemetryAgent experimental overload](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/OpenTelemetryAgent.cs#L80-L113))

### 3.2 Python

- `AgentContext`, `ChatContext`, `FunctionInvocationContext`, seam별 middleware ABC, decorators, `MiddlewareTermination`, `MiddlewareBundle`은 top-level `agent_framework`에서 export된다. ([public exports](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/__init__.py#L174-L194))

([progressive tools experimental](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L295-L378), [bundle experimental](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L680-L752), [buffered_and_gated experimental](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L3228-L3279), [bundle experimental test](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_agent_hooks.py#L237-L242))

## 4. API·타입

### 4.1 .NET

- **Agent seam**: `AIAgentBuilder.Use(...)`는 (1) `Func<AIAgent, AIAgent>`, (2) `Func<AIAgent, IServiceProvider, AIAgent>`, (3) shared run delegate, (4) `runFunc`/`runStreamingFunc` 쌍을 받는다. 따라서 agent-level middleware는 “typed context object”보다 **decorating agent** 또는 **run delegate interception**으로 노출된다. ([AIAgentBuilder overloads](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L72-L178))
- **Decorator base**: `DelegatingAIAgent`는 `Id/Name/Description/GetService/Run/CreateSession/Serialize/Deserialize`를 inner agent로 투명 위임한다. middleware는 이 base를 상속해 일부 메서드만 덮어쓰는 패턴을 쓴다. ([DelegatingAIAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/DelegatingAIAgent.cs#L28-L102))
- **Function seam**: public extension의 callback shape는 `Func<AIAgent, FunctionInvocationContext, Func<FunctionInvocationContext, CancellationToken, ValueTask<object?>>, CancellationToken, ValueTask<object?>>`다. 이 seam은 `FunctionInvokingChatClient`가 있어야만 붙일 수 있다. ([function middleware extension signature](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgentBuilderExtensions.cs#L16-L52))
- **Chat seam(관찰 가능한 표면)**: 이 repo에서 보이는 계약은 `chatClient.AsBuilder().Use(...).Build()`와 `ChatClientAgentOptions` 기반 default stack 구성이다. sample과 `WithDefaultAgentMiddleware()`가 둘 다 같은 형태를 소비한다. ([sample chat builder usage](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/samples/02-agents/Agents/Agent_Step11_Middleware/Program.cs#L36-L53), [default chat stack builder usage](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientExtensions.cs#L52-L139))
- **Built-in decorators**: `LoggingAgent`, `OpenTelemetryAgent`, `MessageInjectingChatClient`, `PerServiceCallChatHistoryPersistingChatClient`, approval-binding/bypass decorators가 prebuilt middleware 역할을 한다. ([LoggingAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/LoggingAgent.cs#L16-L174), [OpenTelemetryAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/OpenTelemetryAgent.cs#L15-L214), [MessageInjectingChatClient](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L14-L391), [default stack order](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientExtensions.cs#L56-L127))

### 4.2 Python

- **Context types**: `AgentContext`는 `messages/session/tools/options/stream/result/metadata/client_kwargs/function_invocation_kwargs/stream_*_hooks`를, `FunctionInvocationContext`는 `function/arguments/session/result/metadata/kwargs/tools`를, `ChatContext`는 `client/messages/options/session/result/metadata/kwargs/function_invocation_kwargs/stream_*_hooks`를 가진다. ([AgentContext](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L96-L210), [FunctionInvocationContext](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L212-L378), [ChatContext](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L381-L475))
- **Seam별 middleware protocol**: `AgentMiddleware`, `FunctionMiddleware`, `ChatMiddleware`는 모두 `process(context, call_next)` 비동기 메서드를 강제한다. ([middleware ABCs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L477-L662))
- **Function decorators**: `@agent_middleware`, `@function_middleware`, `@chat_middleware`는 `_middleware_type` marker를 붙이고, 미표시 callable은 첫 번째 parameter annotation으로 분류된다. ([decorators](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L766-L862), [type determination](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1548-L1616))
- **Bundle/layer types**: `MiddlewareBundle`은 여러 seam을 하나의 불가분 feature로 묶고, `AgentMiddlewareLayer`/`ChatMiddlewareLayer`는 runtime에 middleware를 분류·forward·cache한다. ([MiddlewareBundle](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L680-L752), [ChatMiddlewareLayer](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1202-L1355), [AgentMiddlewareLayer](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1357-L1545))

## 5. 실행 흐름

### 5.1 .NET ordering / nesting

1. `AIAgentBuilder.Build()`는 factory를 **역순으로 적용**하므로, 먼저 `Use()`한 것이 outermost가 된다. ([AIAgentBuilder.Build](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L49-L69))
2. `DelegatingAIAgent`는 기본적으로 inner agent에 완전 위임하고, 개별 decorator가 특정 메서드만 끼어든다. ([DelegatingAIAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI.Abstractions/DelegatingAIAgent.cs#L66-L102))
3. function middleware는 `FunctionInvocationDelegatingAgent`가 `ChatClientFactory`를 덮어써 tool 목록의 `AIFunction`을 `MiddlewareEnabledFunction`으로 바꾸는 방식으로 실행 경로에 들어간다. callback은 `next(context, cancellationToken)`을 호출해 실제 tool invoke로 진행한다. ([FunctionInvocationDelegatingAgent](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgent.cs#L24-L88))
4. default chat stack의 순서는 source comment 기준으로 `ApprovalResponseBinding` → `ApprovalNotRequiredFunctionBypassing` → optional `InvocableFunctionBypassing` → `FunctionInvokingChatClient` → optional `MessageInjectingChatClient` → optional `PerServiceCallChatHistoryPersistingChatClient` → `DeferredOpenTelemetryChatClient`다. ([default chat stack order](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientExtensions.cs#L56-L127))
5. sample은 chat-client middleware, agent-run middleware, function middleware, per-request middleware를 **별도 층으로 중첩**하는 실제 조합 예를 보여준다. ([middleware sample](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/samples/02-agents/Agents/Agent_Step11_Middleware/Program.cs#L36-L132))

### 5.2 Python ordering / nesting

1. `categorize_middleware()`는 bare source normalization 후 bundle을 펼치고, agent/function/chat 카테고리로 분류한다. ([categorize_middleware](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1625-L1734))
2. `AgentMiddlewareLayer.run()`은 agent middleware를 바깥에 두고, chat/function middleware는 `client_kwargs["middleware"]`로 underlying chat-client stack에 forward한다. ([AgentMiddlewareLayer.run](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1450-L1545))
3. 각 pipeline의 pre-order는 registration order이고, post-order는 역순이다. ([pipeline execution](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L974-L1190), [ordering tests](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_middleware.py#L973-L1104))
4. mixed run-level middleware는 loop마다 split된다. chat middleware는 **각 model round**, function middleware는 **각 tool invocation**에 적용된다. ([chat/function split source](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L3238-L3335), [non-streaming split test](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_middleware_with_chat.py#L850-L921), [streaming split test](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/tests/core/test_middleware_with_chat.py#L923-L1001))
5. agent-hooks는 agent/chat/function 3개 middleware를 private로 만들고 `MiddlewareBundle`로만 배포한다. ([agent-hooks bundle intro](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_agent_hooks.py#L8-L20), [bundle build](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_agent_hooks.py#L1612-L1617))

## 6. 상태

### 6.1 .NET

- `ChatClientAgent`는 mutable `ChatClientAgentOptions`를 clone해서 들고, default stack이 활성화되면 wrapped `ChatClient`를 보관한다. ([ChatClientAgent ctor](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientAgent.cs#L118-L146))
- constructor에서 넘긴 tool은 `FunctionInvokingChatClient.AdditionalTools`로 lifecycle 전체에 붙는다. ([default tools wiring](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ChatClientExtensions.cs#L129-L137))
- message injection queue는 session `StateBag`의 `MessageInjectingChatClient.PendingInjectedMessages` 키에 저장되고, 접근은 per-session `SemaphoreSlim`으로 serialize된다. ([MessageInjectingChatClient state and locking](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L44-L61), [enqueue/drain helpers](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L180-L329))
- message injection loop는 response의 `ConversationId`를 다음 iteration의 options로 복사해 conversation continuity를 유지한다. ([conversation id propagation](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L104-L109), [options cloning helper](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L370-L390))
- function middleware decorator는 bare `AgentRunOptions`를 `ChatClientAgentRunOptions`로 승격하면서 `ResponseFormat`, `AllowBackgroundResponses`, `ContinuationToken`, `AdditionalProperties`를 보존한다. ([conversion code](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/FunctionInvocationDelegatingAgent.cs#L30-L67), [preservation test](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/tests/Microsoft.Agents.AI.UnitTests/FunctionInvocationDelegatingAgentTests.cs#L940-L988))

### 6.2 Python

- `AgentContext`/`ChatContext`/`FunctionInvocationContext`는 모두 `metadata`와 mutable `result`를 갖고, Python middleware의 공유 상태/override surface는 이 객체가 된다. ([contexts](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L96-L210), [contexts](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L212-L475))
- `FunctionInvocationContext.tools`는 live mutable tool list이며 `add_tools/remove_tools` mutation은 **현재 batch가 아니라 다음 model iteration**에 반영된다. ([FunctionInvocationContext tools docs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L226-L231), [add/remove docs](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L295-L378), [progressive tool loop wiring](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_tools.py#L3247-L3309))

## 14. Java typed interceptor 결정과 Spring 통합 경계

### 14.1 결정

이 문서의 Java 포팅 결정은 **Python식 3-seam typed interceptor를 public 1급 API로 채택하고, .NET식 prebuilt decorators를 convenience layer로 병행 제공**하는 것이다. 근거는 Python source가 agent/chat/function 각각의 context·result·ordering·partial-install 규칙을 가장 투명하게 드러내고, .NET source가 logging/telemetry 같은 cross-cutting concern을 prebuilt decorator로 제공하는 운영 패턴을 보여주기 때문이다. ([Python seam contexts](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L96-L475), [Python category enforcement](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1643-L1734), [Python agent→chat/function forwarding](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1454-L1472), [UseLogging](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/LoggingAgentBuilderExtensions.cs#L17-L65), [UseOpenTelemetry](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/OpenTelemetryAgentBuilderExtensions.cs#L13-L58))

권장 public shape는 다음과 같다.

- `AgentInterceptor` — run-level input/output, metadata, stream/result hooks
- `ChatInterceptor` — model-call messages/options/result
- `FunctionInterceptor` — validated tool args/result/live tools mutation
- `InterceptorBundle` — agent-hooks 같은 다중 seam feature를 부분 설치 불가로 묶는 opaque 단위

이렇게 해야 approval/message injection처럼 **session-backed state machine**을 core runtime이 계속 소유하면서도, logging/telemetry/redaction 같은 concern은 Spring-friendly wrapper로 쉽게 묶을 수 있다. ([Python bundle invariants](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L680-L752), [Python message injection session ownership](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_sessions.py#L1298-L1432), [.NET message injection session ownership](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L24-L61))

### 14.2 Spring 통합 경계

Spring은 **bean discovery / ordering / conditional auto-configuration**까지만 맡아야 한다. 다음은 core runtime 경계 안에 남겨야 한다.

- interceptor pre/post ordering과 outermost/innermost 규칙
- session state bag / queue ownership
- approval/message injection/persistence state machine
- gated stream sealing rules

즉 Spring AOP나 BeanPostProcessor가 tool/message approval state를 직접 재구성하거나 interceptor 순서를 재해석하면 안 된다. Spring은 `List<AgentInterceptor>` 정렬, convenience decorator bean 등록, observability bean wiring까지만 담당하고, 실행 계약은 framework core가 고정해야 한다. ([AIAgentBuilder outermost rule](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/AIAgentBuilder.cs#L54-L67), [Python supported-category enforcement](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_middleware.py#L1655-L1734), [MessageInjectingChatClient session queue](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/MessageInjectingChatClient.cs#L180-L329), [ResponseStream sealing](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L3552-L3624))
