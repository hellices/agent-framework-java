# 06-tool-approval

이 문서는 Agent Framework의 **tool approval**만 다룬다. 구체적으로는 **사용자 승인 요청/응답 타입**, **approval-required tool wrapper 의미**, **middleware/state/rule 모델**, **argument-aware standing approval**, **거부/오류/재개 흐름**, **session 연계**를 설명한다. **MCP 자체 승인 프로토콜**과 **workflow/HITL orchestration**은 별도 문서 범위이므로 여기서는 경계만 기술한다. reviewed source 기준으로 .NET은 두 층이 있다: (1) `FunctionInvokingChatClient` 위에서 tool-approval request/response를 보강하는 **chat-client decorator 층**과, (2) caller-facing “don’t ask again”/queueing을 제공하는 **`ToolApprovalAgent` harness 층**이다. Python은 (1) core `Content`/tool-loop 차원의 approval request/response semantics와, (2) opt-in `ToolApprovalMiddleware`의 standing rule/queueing 층으로 나뉜다. ## 목적

tool approval 기능의 목적은 모델이 선택한 tool call을 **무조건 즉시 실행하지 않고**, 특정 call을 사용자 승인 대상으로 surface하며, 사용자가 준 decision을 **같은 logical tool call**에 다시 결합해서 실행/거부/자동승인 규칙 저장까지 수행하는 것이다. .NET chat-client decorator는 “모델이 surface한 approval request와 caller가 돌려준 approval response가 정확히 같은 call에 대응한다”는 보증을 강화하고, Python core/harness는 approval request를 user-input-required content로 다루고 session state에 standing rule과 queued request를 저장한다. [ApprovalResponseBindingChatClient.cs#L22-L38](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/ChatClient/ApprovalResponseBindingChatClient.cs#L22-L38) [ToolApprovalAgent.cs#L22-L50](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/dotnet/src/Microsoft.Agents.AI/Harness/ToolApproval/ToolApprovalAgent.cs#L22-L50) [_types.py#L1273-L1313](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_types.py#L1273-L1313) [_harness/_tool_approval.py#L343-L379](https://github.com/microsoft/agent-framework/blob/d0a4165f170193ba1d026a259af40d35bb7eaefe/python/packages/core/agent_framework/_harness/_tool_approval.py#L343-L379)
